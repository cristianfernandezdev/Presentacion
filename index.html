Mapeo Tecnológico Curricular

Acceso a Datos

PostgreSQL / Flyway

El dinero no perdona fallos. Implementación de base de datos relacional con control estricto de transacciones (ACID). Versionado de esquema automatizado mediante Flyway para despliegues seguros.

Serv. y Procesos

Spring Boot / JWT

El núcleo seguro. Autenticación stateless y delegación de tareas pesadas (auditorías, logs) a hilos secundarios concurrentes para no bloquear el Event Loop principal del servidor.

Dispositivos Móviles

Kotlin / Retrofit

El cliente móvil es totalmente "estúpido". No calcula saldos ni procesa lógica; se limita a consumir la API de forma asíncrona mediante corrutinas para ofrecer una UI a 60fps.

Interfaces (Backoffice)

JavaFX / OpenAPI

Panel de control administrativo para empleados. Consume los mismos endpoints que la app móvil, demostrando que la API es universal, validada mediante roles de auditor (RBAC).

Viabilidad y Lógica de Negocio

Ingeniería Financiera (El Modelo MVP)

El sistema incluye un motor de comisiones automatizado. Cobrar no es un "botón en la pantalla", es un reto de atomicidad en el backend.

  • Bloqueo Transaccional (@Transactional): Si un usuario solicita una transferencia inmediata, Java ejecuta tres operaciones en bloque: resta al emisor, suma al receptor y desvío de la comisión (1%) a la cuenta operativa del banco. Si un paso falla, se ejecuta un Rollback automático.
  • Sistemas de Gestión (Odoo): Para justificar el módulo de ERP, delegamos la contabilidad. Cuando Spring Boot consolida la comisión, lanza un Webhook a Odoo para generar el apunte contable y el ticket fiscal sin ensuciar la base de datos del banco.
